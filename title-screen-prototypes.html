Trade-offsFurthest from vanilla; needs custom keyboard/controller navigation, and the 2×2 grid is harder to scan than a list for some players.

How this lands in the mod (Fabric 1.21.11)

  • Screen swap: mixin TitleScreen (or cancel it and set our own Screen) so Orbit's title screen replaces vanilla. Vanilla widgets are recreated as custom ButtonWidget subclasses with our own renderWidget.
  • Background: no shader needed — draw it per frame with DrawContext: a black disc, a stack of rotating ellipse arcs for the disk (additive-ish alpha), a bright photon ring, and 2–3 warped arcs above/below for the lensing. A pre-baked 256×256 noise sprite reused with offsets covers the starfield cheaply.
  • Perf: ~40 arc segments per frame is nothing, but I'd cap the animation to the title screen only, and skip it entirely when the window is unfocused or the "animation" toggle is off.
  • Buttons: real widgets, not painted pixels — keyboard focus, narration and the existing vanilla sound events keep working.
  • Splash text: keep vanilla's splash mechanic (random line from splashes.txt, which already supports wrapping) so it rotates as usual, just restyled and rotated.
  • Config: Title Screen module with a variant choice, animation on/off, spin speed, and show/hide logo — all saved in orbit.json like everything else.
