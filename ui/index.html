Element mapping

If a slot is wrong or empty, click Pick and then click that element on the page. This is how the re-skin adapts to any site without hard-coded selectors.

Known roles: header · messages · composer · send · sidebar · newChat · status. Anything unmapped is simply left out of the new layout; nothing is invented.

What this can and can't do

  • Can — take over layout, order, typography, spacing and visual language.
  • Can — keep 100% of the site's behaviour, because the real DOM nodes are moved.
  • Can't — add features the site doesn't have.
  • Can't — restructure a site's internals; if a chat window is one giant canvas, there are no pieces to move and slots will report as missing.
